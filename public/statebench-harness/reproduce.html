This site publishes archived results. It does not run inference, collect keys, or submit prompts to any API. Run model experiments from the source repository on your own machine.

Rebuild the measured charts

From the standalone repository checkout, Python 3.10+:

python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest -v
python summarize_live.py results-qwen06 results-qwen17 --output results-models
python build_pages.py
python -m http.server 8000 --directory docs

Open http://localhost:8000. Chart rebuilding uses shipped measured records; it makes no model calls. The Pages builder itself uses only Python’s standard library.

Repeat actual inference

The repository’s MODEL_RUNS.md describes CPU runtime setup and pinned GGUF downloads. Use these revisions and SHA-256 hashes. Provision Qwen3 0.6B on port 8090 and 1.7B on 8091, one CPU thread per server, 8192-token contexts, no JSON grammar. Then run:

python live_experiment.py --base-url http://127.0.0.1:8090/v1 --model Qwen3-0.6B-Q4_K_M --context 8192 --max-tokens 256 --raw-max-tokens 64 --lengths 8 32 128 --samples 1 --chunk-size 8 --timeout 600 --output results-qwen06
python live_experiment.py --base-url http://127.0.0.1:8091/v1 --model Qwen3-1.7B-Q4_K_M --context 8192 --max-tokens 256 --raw-max-tokens 64 --lengths 8 32 128 --samples 1 --chunk-size 8 --timeout 600 --output results-qwen17

CPU runs take time. The default task seed is 42. Source LIVE.md documents semantics, validation, thinking settings, context checks and a 4B/8B Q4 local deployment target for a 16GB RTX 5070 Ti. That larger GPU path was not measured here. API credentials, if used for an optional external provider, stay in environment variables; they never belong in the static site.

Know what was measured

Each model has 36 case/method records: four difficulties × three lengths × three methods. Each curve point aggregates four synthetic cases. Raw and model-written state use model predictions; the tool arm explicitly delegates state updates to a deterministic interpreter. An interpreter alone already executes these formal programs correctly.

No frontier 13% result, official StateBench dataset reproduction, Gated DeltaNet training, recurrent hybrid, or 64K live inference is claimed. Generation/interpreter tests cover 64K assignments. Invalid model output counts as incorrect; transport/context failures have separate counts.

Publish to GitHub Pages

After this source and generated docs/ are in your GitHub repository’s main branch, open Settings → Pages → Build and deployment. Choose Deploy from a branch, branch main, folder /docs, then save. Every asset and data URL is relative, so project subpaths work.

This local build does not create a remote repository, push files, change GitHub settings, or confirm a deployment. Rebuild and commit docs/ whenever finalized source results change.
