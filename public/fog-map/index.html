team habit ownership

backend engineer

BRING YOUR OWN SPEC

New analyses run in the CLI.

Clone this repository and use Python 3.10+. The dependency-free offline demo runs immediately and is clearly labeled as authored rules:

python fog.py sample-spec.md --backend offline --out output

For three actual model calls on your own spec, install Ollama, pull the quantized 4B model, then run:

ollama pull qwen3:4b
python fog.py your-spec.md --backend ollama --out output-new

See the repository README for CPU reproduction, optional API configuration, and failure logs. API keys stay in shell environment variables; this site collects nothing.
