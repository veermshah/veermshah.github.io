03 / WHAT THIS CAN TELL US
A small experiment.
A bounded conclusion.
The paper’s claim
DynaFlow, arXiv:2610.34467, Table 1, reports trained Qwen3.5-27B Forced collaboration at 100% on AIME 2024–2026, with 88.08% overall versus 77.18% for the strongest baseline. Its solo CoT AIME 2026 figure is 86.67%, correcting the brief’s approximately 52%.
These are author-reported claims, not independently confirmed by this prototype.
What we actually measured
Prompted workflows on an untrained-for-orchestration Qwen3-0.6B Q4_K_M CPU model. No QLoRA training; constrained Python coordination instead of the paper’s general JavaScript. All arms use the same frozen weights.
Two fixed convenience cohorts, six tasks per family, with different disclosed budgets. No original six-benchmark evaluation or generalization claim. These numbers neither confirm nor refute the paper’s trained 27B result.
Where the edges are
Public tasks may be in model training data. Exact-match grading can reject verbose but related answers. Uniform XML answer-wrapper normalization changed one official fixed-pipeline score; the original derived scores remain available. Shared-server queuing makes latency unsuitable for isolated throughput claims.
The initial server interruption completed no model calls; its technical failures are excluded from accuracy evidence. The deterministic smoke-test surrogate is also excluded from this explorer.
Reproduce, then scale
The local deployment target is an RTX 5070 Ti with 16GB VRAM: Qwen3 4B Q4_K_M, or 8B Q4_K_M after measuring memory headroom, starting at 8192 context. This build measured CPU inference, not GPU VRAM.
